# Assignment 1

Requires Python 3 and an internet connection (the data is downloaded from Our World in Data).

## macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Windows

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Each plot opens in its own window; close it to show the next one.
